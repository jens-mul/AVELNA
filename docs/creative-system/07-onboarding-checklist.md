## First hour of a future AVELNA creative session (without generation spend)

1. Read canonical manuals and most recent approval history.
2. Fetch live Element registry and check no deletions/duplicates/version changes.
3. Review one *individual* candidate at a time: Front, Back, Upper, Lower; compare against canonical identity.
4. Decide which views meet resolution/identity/foot anatomy requirements. Record owners' exact approval of image SHA.
5. Repeat with Bathroom original vs Mid/Close/Shower, noting that these are crops/motion frames, not new architectural truth.
6. Repeat with Stone top vs warped oblique and crops, noting product-rights and true geometry gaps.
7. Pick **one shot** to advance — likely Shot 2 only. Write a self-contained start frame in the same location, not a contact sheet.
8. Validate continuity/physics at still level with dry floor and direct stepping path.
9. Select model and perform only quote/preflight. Present actual expected credit charge.
10. After a scoped grant, run **one** job and QA its actual frames. Report exact product/room/character drift, not just aesthetic quality.

## Failure reduction checklist

- *Model ignored references?* Check actual media role and Element support, not only prompt words.
- *Collage instead of one still?* Reject; explicitly require one subject/view, one crop, no grid and **inspect**.
- *Different room?* Prefer original image or motion-frame crop; if impossible, build a consistent 3D scene instead of lying about source angle.
- *Product waves wrong?* Use source pixel layer; reject generated product; don't present 2D warp as actual 3D.
- *Foot anatomy wrong?* Correct standalone foot/leg reference, not a newly invented character.
- *Water everywhere?* Explicit contact path, source, direction, limited number of droplets and dry floor.
- *Video aspect wrong?* Probe actual accepted endpoints and check output dimensions, don't stretch for a website hero.
- *Credits unexpectedly spent?* Stop, reconcile account/job history; don't start another provider job.
- *Old Element still visible?* Mark deprecated and omit from lookup; deleting media placement doesn't delete Element.

A completed concept-reference library and a visually beautiful 5-second video are important milestones **but not a final live advertisement**.
